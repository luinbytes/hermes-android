Version strings alone do not replace a commit pin. Status is intentionally strict: **implemented** means a real client path exists in this repository; **foundation** is tested domain/transport work without a complete surface; **blocked** identifies a concrete upstream contract gap; **not implemented** is not shipped as decorative UI.
